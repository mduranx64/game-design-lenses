# Example: a short rescue mission

**Proposed beats:** Find a distant signal (curiosity), learn a safe traversal action (confidence), choose a risky shortcut (tension), pause at a shelter with a new clue (relief and anticipation), combine learned actions to reach the survivor (payoff), then see the result (resolution).

This is an interest hypothesis, not a fixed requirement that every rescue game has six beats. A cautious player may spend much longer at the shortcut than an expert.

**Problem report:** The shelter pause feels empty. Before adding combat, test whether its clue changes the player's understanding of the rescue. If it does not, shorten the pause or make the discovery consequential.

**Evidence to collect:** Where players pause voluntarily, where they become confused, what moment they remember, and how that differs from the intended curve.
