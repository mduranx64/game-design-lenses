# Example: the bridgekeeper's debt

**Situation:** The player needs to cross. A bridgekeeper needs medicine delivered before opening the bridge.

**Decision:** Deliver medicine, repair an alternate crossing, or negotiate with evidence found earlier. Each route reaches the next region; consequences persist as a relationship, a new path, or an obligation.

**State:** medicine_delivered, alternate_crossing_repaired, debt_accepted. Crossing the region boundary does not erase these flags.

**Divergent walkthrough:** A player repairs the crossing without speaking to the keeper. Later dialogue acknowledges that crossing and does not thank the player for medicine. The future medicine request remains available if it still makes sense.

**Scope control:** Rejoin the main journey after the crossing while varying specific future reactions. Do not promise three separate campaigns unless the project can support them.
