# Example: does steering a wind sail feel interesting?

**Risk:** The core steering action may feel sluggish even if the planned campaign is appealing.

**Prototype:** One sail, a gust control, a destination, and immediate direction feedback. Use a small interactive mockup if the question is continuous steering feel. A paper direction-and-distance game can test strategic route choice but cannot establish control responsiveness.

**Observation:** Watch whether players deliberately alter the sail and correct errors, and ask what they expected a gust to do. Compare the behavior with the intended action loop.

**Decision:** Keep the model if players can learn its response and make meaningful corrections; revise it if outcomes seem arbitrary. The exact criterion needs agreement for this project. A campaign map, upgrade shop, and polished scenery are downstream of this uncertainty.
