# Example: a calm game with a punishing streak

**Purpose supplied by the creator:** Offer a few minutes of relaxed reflection.

**Mechanic:** Missing one daily visit removes a month of garden growth.

**Conflict:** The loss rule could create obligation and anxiety, undermining the intended relaxed return. This is a design risk, not a diagnosis of player harm.

**Alternative:** Preserve existing growth and let visits add new variation. If continuity matters aesthetically, show seasons changing without treating absence as failure.

**Assessment:** Ask returning players what motivated the visit and how the missed day felt; examine whether the revised rule still supports the creator's experience promise. Session frequency alone does not establish wellbeing.
