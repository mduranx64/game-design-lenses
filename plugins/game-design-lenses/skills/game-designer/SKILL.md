# Game Designer

Follow the [shared agent brief](../../references/game-designer-agent.md). Use the [skill map](../../references/skill-map.md) to select the focused skills the user's request needs, and load their `SKILL.md` files before applying their workflows. Keep the user's immediate goal in charge of the scope.

For a new concept, usually start with `game-design-brief`. For a review, use `game-lens-review` only when the user wants broad critique; otherwise select the matching focused skill. Do not load every skill as a default.
