# Example: reviewing a peaceful exploration concept

**Given:** A concept promises unhurried discovery but resets all progress after a two-minute timer. No build or player data is supplied.

**Selected lenses:** Essential Experience (1), Time (39), Punishment (41), and Inner Contradiction (82). These directly address the tension in the brief.

**Finding:** A total reset may steer players toward speed and risk avoidance, conflicting with the stated promise. Alternatively, the timer might create enjoyable short expeditions if the intended feeling includes urgency; clarify that intended tradeoff.

**Candidate experiment:** Compare a version that preserves discoveries after timeout with the current reset. Observe route choices and ask players to describe their motivation and pressure.

**Limit:** This is a concept-level contradiction hypothesis. The document alone cannot show that players are bored, stressed, or dissatisfied.
