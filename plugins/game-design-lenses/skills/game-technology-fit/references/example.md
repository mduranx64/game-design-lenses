# Example: a crowd reacting to music

**Foundation:** Many characters must react recognizably to player rhythm. **Enhancement:** Every character has a unique high-detail face.

**Unknown:** Whether the target device can present the required crowd and immediate rhythm feedback together.

**Spike:** Use representative character count, animation variety, camera coverage, and input path. Measure frame behavior and input response on the actual target setup. Choose limits from the project's needs, not an arbitrary universal frame budget.

**Fallback:** Reduce visual uniqueness or simulate distant characters more simply before removing the timing feedback that carries the experience. Verify that the change preserves readable group response.

No current engine claim is implied by this example.
