# Skill map

Select the workflow that matches the deliverable. Use the lens review for a broad critique; combine focused workflows only when the requested result needs them.

| Task | Skill | Example request |
| --- | --- | --- |

## Likely boundaries

- Mechanics specifies rules; balance compares how options and outcomes behave; economy follows resource flows and progression.
- Player experience models motivations and comprehension; pacing shapes sequences; playtesting gathers or analyzes real evidence.
- Narrative connects choices to story consequences; world/characters defines the setting and cast; level design organizes playable space.
- Prototyping resolves a consequential unknown; technology fit isolates capability risks; documentation communicates the resulting decisions.
- A request for code implementation can use relevant design decisions, but these skills do not substitute for the engine or language tools required to implement it.
